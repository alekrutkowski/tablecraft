MAKE YOURSELF AT HOME

Your pipeline, step by step

1

Choose a table

Choose multiple CSV, TSV, fixed-width or Excel files in one selection. Each gets a file-based R name and an import statement. Search, preview, delete, and insert table names from Available tables or Manage. Related examples are chosen automatically for joins.

2

Build your chain

Use Add a step, then fill in its settings. Column chips insert names. Move, duplicate or disable steps from the pipeline. Click the eye on a step to preview the result up to that point.

3

Make the code your own

The editor is real R. Typing switches to Text mode. Sync to Visual parses your edits into guided or custom R steps and preserves arbitrary scripts. Code hints propose table names, columns, and functions; turn them off above the editor. Press F1 for function help. Use Format R to hard-wrap text with nested indentation. Comments: on/off controls comments in the editor and R output while preserving hashes inside strings.

4

Keep work moving

Turn off Live preview for slower transformations; syntax checks continue. Preview pages show a bounded slice of the full result. Export CSV downloads the full table. Stop restarts the R worker when a calculation takes too long.

Saving your work

Your workspace and successfully imported files are saved in this browser for refresh recovery. Save recipe also downloads a portable JSON copy without file contents. Restart R keeps your work; Restart app asks for confirmation before clearing the saved workspace and file copies. Download the R script to run the transformation in desktop R.

Local execution

The first launch downloads webR and R packages. Computation runs locally; imported file copies and recovery state stay in this browser. Browser memory limits apply. Custom R may make network requests if you explicitly write them.
